# 🔍 Linear Search in Java

This repository contains a simple implementation of the **Linear Search** algorithm in Java.

## 📌 What is Linear Search?

Linear Search is a searching algorithm that checks each element of an array one by one until the target element is found.

If the target is found, it returns its index.  
If the target is not present, it returns `-1`.

🧠 Example
Input
nums = [10, 20, 30, 40]
target = 30

Output
2

Because 30 is present at index 2.

⏱️ Complexity
Time Complexity: O(n)
Space Complexity: O(1)
